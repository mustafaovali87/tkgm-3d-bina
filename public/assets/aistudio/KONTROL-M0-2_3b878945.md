## F1 — YARIM, düzeltilmeli (zorunlu)

`npm ci` Windows'ta hâlâ hata veriyor:

```
npm error code EUSAGE
npm error `npm ci` can only install packages when your package.json and package-lock.json are in sync.
npm error Missing: @tailwindcss/oxide-win32-x64-msvc@4.3.5 from lock file
npm error Missing: lightningcss-win32-x64-msvc ... (ve diğer platform paketleri)
```

- **Neden:** `package-lock.json`, Linux'ta ve `node_modules` klasörü zaten varken üretilmiş. Bu durumda npm, başka platformların isteğe bağlı paketlerini kilit dosyasına yazmıyor.
- **Neden zorunlu:** Teslim hedefi Windows. Kilit dosyası Windows'ta çalışmazsa paketleme ve bağımsız denetim tekrarlanamaz.

**Yapılacak:**
1. `node_modules` klasörünü ve `package-lock.json` dosyasını sil.
2. `npm install` ile kilit dosyasını yeniden üret.
3. `package-lock.json` içinde şu girdilerin bulunduğunu kontrol et:
   - `@tailwindcss/oxide-win32-x64-msvc`
   - `lightningcss-win32-x64-msvc`
   - `@esbuild/win32-x64`
4. `docs/ADIM_NOTU.md` içinde F1 durumunu "YAPILDI (win32 girdileri doğrulandı)" yap. GitHub'a gönder.

Ben bu bilgisayarda temiz `npm ci` ile tekrar deneyeceğim.
