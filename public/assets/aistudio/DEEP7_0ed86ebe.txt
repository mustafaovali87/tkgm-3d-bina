**Kapı alt boşlukları:**

- **+50 mm**: Ornek2 (91/91), Ornek3 (2139/2139), Ornek5 (184/184)

**Buradan çıkan kesin sonuçlar:**

2. **"Kapı yüksekliği 2100 mm" varsayılanı yanıltıcı.** Örneklerde 205–485 cm aralığında.

**Gemini v6 §2.1'deki hata:** "Varsayılan doorHeight = 2100 mm" yazıyor. Bu, 7 örnekten yalnızca 1'ine (Ornek1 kısmen) uyuyor. Doğru yaklaşım: **açıklık tipi kütüphanesi** (Claude6 C6-01).

### 1.2 N13 — Delik ↔ Duvar Dikey Kenarı Mesafesi

### 1.3 N14 — Duvar Kalınlığı Sürekli Dağılım

**En kritik bulgu:** Ornek5, Sincan, Amasya, Ret dosyasında **8–19 cm arası sürekli dağılım** var ve üçü kabul edilmiş, biri sadece başka nedenlerle ret edilmiş (geometrySuitability=1005).

**Bu, K56-ek sabit duvar kalınlığı kuralının reddi için kesin kanıttır.** Çünkü:

### 1.5 N16 — Arsa Payı Toplamı ≠ 1 Kabul Edilmiş

| Dosya | Benzersiz BB | Σ pay |
|---|---|---|
| Ornek1 | 67 | 362/363 |
| Ornek2 | 13 | 1/1 |
| Ornek3 (B blok) | 173 | 471197/954497 (≈0.494) |
| Ornek4 | 12 | 4542/8861 (≈0.513) |
| Ornek5 | 24 | 8/9 |
| Ornek6 | 2 | 1/1 |

**Sonuçlar:**
1. **Ornek1 ve Ornek5'te küçük eksik** (1/363 ve 1/9) kabul görmüş → uyarı vermemeli
2. **Ornek3 ve Ornek4'te ~0.5** çünkü parselde başka blok var → tek blok GML'de toplam 0.5 normal
3. **Dubleks parçalar üzerinden toplanırsa 1'den büyük çıkar** (Ornek1: 2281/2178)

**Doğru yaklaşım:**
- V-198 **BİLGİ** (tek blok GML'de) / **UYARI** (kullanıcı parseldeki tüm blokları beyan ettiyse)
- Toplam **benzersiz BB** üzerinden
- BigInt aritmetiği (doğru) + BB kimliği tekilleştirme (eksik) → her ikisi birlikte

**Benim 6. turdaki `N % L === 0n` hatam:** Fazla payı (N = 2L) da doğru sayardı. **Doğru kod:**

```ts
function checkLandShare(parts: {pay: bigint, payda: bigint}[]): Result {
  // EKOK
  let L = 1n;
  for (const p of parts) L = L / gcd(L, p.payda) * p.payda;
  // Toplam
  let N = 0n;
  for (const p of parts) N += p.pay * (L / p.payda);
  // Kontrol - N === L olmalı, N % L === 0n YETMEZ
  if (N === L) return { ok: true };
  if (N < L) return { status: 'BILGI', summary: `Eksik: ${L-N}/${L}` };
  return { status: 'UYARI', summary: `Fazla: ${N-L}/${L}` };
}
```

function detectRegime(gml: ImportedModel): 'S' | 'E' | 'unknown' {
  const indicators = {
    hasMaksIntegrationState: gml.building.attributes.maksIntegrationState !== undefined,
    hasPropertyLot: gml.independentSections.some(s => s.propertyLot !== undefined),
    hasRegisteredQuality: gml.independentSections.some(s => s.registeredQuality !== undefined),
    hasDoors: gml.openings.filter(o => o.kind === 'door').length > 0,
    hasWindows: gml.openings.filter(o => o.kind === 'window').length > 0,

}

### D7-05 — Kapı Sığma Kontrolü (Eğik Tavan)

Claude6 C6-10'u somutlaştırıyorum:

```typescript
function checkDoorFit(
  door: { wallId: string, spanA: Pt3, spanB: Pt3, zTop: number },
  wall: { polygons: Pt3[][] }
): { fits: boolean; suggestion?: string; minWallTop: number } {
  // Kapı aralığındaki duvar üst kotunu bul
  const wallTopAtSpan = findMinWallZ(wall, door.spanA, door.spanB);
  const minWallTop = wallTopAtSpan;
  
  if (door.zTop <= minWallTop - 10) {
    return { fits: true, minWallTop };
  }
  
  // Sığmıyor - öneri
  const shift = findBestShift(door, wall);
  return {
    fits: false,
    minWallTop,
    suggestion: shift 
      ? `Kapıyı ${shift.cm} cm ${shift.direction} kaydırırsan sığar`
      : 'Bu duvarda sığacak yer yok',
  };
}
```

**Kullanım senaryosu:** Çatı aralı eğik tavanlı oda. Kapı yüksek tarafta olmalı. Alçak tarafta çizersen uyarı + öneri.

### D7-11 — F3-A1 İçin "Tamponlama" Algoritması (Kesin)

Claude6 §11'i benimsiyorum ve **kod düzeyine indiriyorum**:

```typescript
// v1: Tamponlama ile oda çıkarma (Clipper2)
function extractRoomsFromLines(
  lines: Line2D[],
  toleranceMm: number = 5,
  bufferWidthMm: number = 10  // duvar çizgisi kalınlığı
): RoomPolygon[] {
  // 1. Snap-round: her çizgiyi yakın mm'ye yuvarla
  const snapped = lines.map(line => snapRound(line, toleranceMm));
  
  // 2. Açık yolları ince şeritlere tamponla
  const buffered = snapped.map(line => 
    Clipper2.OffsetOpenPath(line, bufferWidthMm / 2, EndType.Butt)
  );
  
  // 3. Şeritleri birleştir → duvar ağı
  const wallNetwork = Clipper2.Union(buffered);
  
  // 4. PolyTree'de delikler = oda adayları
  const polyTree = Clipper2.BuildPolyTree(wallNetwork);
  const rooms = polyTree.children;  // Duvar dışı boşluklar
  
  // 5. Tampon payını geri ver (5 mm dışa ofset)
  const restored = rooms.map(room => 
    Clipper2.InflatePaths([room.outer], -bufferWidthMm / 2, JoinType.Miter)
  );
  
  // 6. Alan filtresi
  return restored.filter(room => {
    const area = Clipper2.Area(room) / 1e6;  // mm² → m²
    if (area < 0.5) return false;  // Kolon/şaft adayı
    if (area < 1.0) return { ...room, uncertain: true };  // Sor
    return true;  // Oda
  });
}
```

**Neden çalışır:**
- Clipper2 OffsetOpenPath **açık yollarda** çalışır
- Union kapalı şeritler üzerinde çalışır
- PolyTree çıktısında **iç boşluklar** (= odalar) otomatik çıkar
- 5 mm snap-round uç-uca açıklıkları kapatır
- 10 mm tampon genişliği = duvar çizgisi kalınlığı
